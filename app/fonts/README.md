# Fuentes incrustadas

La interfaz incrusta estas fuentes en `docs/index.html` para que se vea igual sin conexión y sin pedir nada a servidores externos. Son subconjuntos latinos tomados de los paquetes de Fontsource (npm, versión 5.1.1).

| Archivo | Familia | Uso |
|---|---|---|
| `atkinson-hyperlegible-latin-400-normal.woff2`, `…-700-normal.woff2` | Atkinson Hyperlegible | Texto |
| `bricolage-grotesque-latin-opsz-normal.woff2` | Bricolage Grotesque (variable: peso 200–800, tamaño óptico 12–96) | Títulos |
| `ibm-plex-mono-latin-400-normal.woff2`, `…-500-normal.woff2` | IBM Plex Mono | Cifras |

Las tres familias se distribuyen bajo la licencia SIL Open Font License 1.1 (archivos `LICENSE-*.txt`), que permite incrustarlas y redistribuirlas.
